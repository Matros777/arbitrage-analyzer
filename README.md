# Arbitrage Analyzer Pro

Professional multi-DEX arbitrage analyzer with real-time price spread detection, liquidity analysis, and auto-update every 5 minutes.

## Features

- 🔍 Real-time multi-DEX price comparison
- 💰 Automatic spread detection
- 📊 Liquidity and volume analysis
- 🔄 Auto-update every 5 minutes
- 🌍 English/Russian explanation toggle
- 🚀 Deployed on Vercel

## Tech Stack

- FastAPI
- DexScreener API
- Vercel

## Quick Start

```bash
pip install -r requirements.txt
python app_arbitrage_v3.py
